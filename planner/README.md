# 🗓️ Planner — 주간·월간 할일/일정 플래너

엑셀 주간·월간 플래너를 대신하는 가벼운 Windows 데스크톱 앱입니다. 트레이에 상주하고, 최대화 화면에
꽉 차게 그려집니다. Tauri 2 (Rust + WebView2) 위에 화면은 프레임워크 없는 HTML/CSS/JS로 되어 있습니다.

## 기능

- **주간**: 위쪽에 이번 주 목표(4줄)와 주간 메모, 아래 4×2 격자에 요일별 11줄(상태 · 시간 · 할일 · 구분)과 "다음 주로 넘길 일" 칸
- **월간**: 달력(칸 높이에 맞춰 일정 줄 수가 바뀌고, 넘치면 "+N개 더"), 이달의 목표(6줄), 월간 할일(화면 높이에 맞춰 늘어나며 최대 60줄, 마감일이 지나면 빨간 글씨)
- **연간**: 12개월을 한 화면에. 날짜를 누르면 그 주, 월 이름을 누르면 그 달로 이동
- **상태**: 동그라미 클릭 → 완료 ✔ → 이월 → → 취소 ✕ → 비움 (우클릭: 비움, Shift+클릭: 거꾸로)
- **이월**: 다음 날(월간 할일은 다음 달, "다음 주로 넘길 일"은 다음 주 첫날)에 자동 복사. 이월을 풀면 손대지 않은 복사본은 지워짐
- **구분**: 업무 · 개인 · 가족 · 약속 (색 칩)
- **트레이 상주**: 창의 X는 숨기기. `Ctrl + Alt + P`로 어디서든 열기/숨기기. Windows 시작 시 자동 실행(설정)
- **화면 배율**: 자동(넓은 화면에서 글자·칸을 함께 키움) 또는 100~130% 직접 선택
- **그 밖에**: 다크 모드, 일요일/월요일 시작, 공휴일·대체공휴일 표시와 사용자 휴일 추가, 엑셀(.xlsx) 내보내기, JSON 백업, 되돌리기(`Ctrl+Z`)

## 데이터

- `문서\Planner\planner-data.json`: 입력하는 대로 자동 저장(임시 파일에 쓴 뒤 교체)
- `문서\Planner\backups\`: 하루 한 번, 덮어쓰기 전 상태를 보관(14일)
- `문서\Planner\exports\`: 엑셀·JSON 내보내기
- 외부로 보내는 것은 없습니다. (Google 드라이브 동기화는 [docs/SYNC.md](docs/SYNC.md)에서 설계 중)

## 개발

```bash
cd planner
npm install
npx tauri dev          # 개발 모드
npx tauri build        # 설치 파일(NSIS) → src-tauri/target/release/bundle/nsis/
npm run preview        # 화면만 한 장짜리 HTML로 묶기 → preview/planner-preview.html (브라우저 미리보기, 예시 데이터 포함)
```

- 화면: `src/` (`index.html`, `style.css`, `app.js`, `holidays.js`). 빌드 도구 없이 그대로 쓰입니다.
- 본체: `src-tauri/src/main.rs`. 데이터 저장·백업, 엑셀 내보내기, 트레이, 전역 단축키, 자동 실행.
- 브라우저에서 `src/index.html`을 열면 localStorage에 저장하며 화면만 확인할 수 있습니다.
- GitHub Actions **Planner Windows Build** 워크플로가 `planner/**` 변경 때마다 Rust 테스트와 설치 파일 빌드를 돌립니다.
  설치 파일은 실행 결과의 `Planner-windows` 아티팩트로 받을 수 있습니다.

## 설계 결정 (인수인계용)

다른 세션이나 다른 사람이 이어서 작업할 때 지켜야 할 결정들입니다.

| 항목 | 결정 |
|---|---|
| 한 주의 시작 | 기본은 **일요일**. 설정에서 월요일로 전환 |
| 주차 | 그 주 **목요일**이 속한 달 기준 (예: 2026-12-27~2027-01-02 주는 "12월 5주") |
| 주간 데이터 키 | 그 주 목요일 날짜(YYYY-MM-DD). 일/월 시작을 바꿔도 목표·메모가 유지되게 하려는 것 |
| 화면 기준 해상도 | 최대화 상태에서 3840×2400(200%), 2560×1440(100%), 1920×1080(100%)에서 스크롤 없이 꽉 차야 함 |
| 줄 수 | 주간 하루 11줄 · 넘길 일 11줄 · 주 목표 4줄 / 월 목표 6줄 · 월간 할일은 높이에 맞춰 가변(최대 60) |
| 공휴일 | `src/holidays.js`. 2026-12 ~ 2027 (우주항공청 2027년 월력요항 기준, 제헌절·노동절 포함, 대체공휴일 7일). 해마다 추가 필요 |
| 회사 PC 빌드 | 동기화 없이 로컬 파일만 사용. 동기화는 개인용 빌드에서만 켬 ([docs/SYNC.md](docs/SYNC.md)) |
| 앱 식별자 | `com.planner.desktop`. 이미 설치된 버전과 같은 앱으로 인식되도록 바꾸지 않음 |
