🗓️ Planner

Planner는 개인이 쓰는 주간·월간 할일/일정 플래너 앱입니다. Windows 데스크톱과 안드로이드 태블릿에서 같은 플래너를 쓸 수 있도록, 사용자가 원할 때 사용자 본인의 Google 드라이브 앱 전용 저장공간(appDataFolder)으로 플래너 데이터를 동기화합니다.

  • 요청하는 Google 권한: https://www.googleapis.com/auth/drive.appdata 하나 — 이 앱이 만든 숨김 파일만 읽고 씀
  • 사용자의 다른 드라이브 파일은 볼 수 없으며, 데이터를 외부 서버로 보내지 않습니다
