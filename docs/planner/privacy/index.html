Planner 개인정보처리방침

시행일: 2026년 11월 20일

1. 처리하는 정보

Planner는 사용자가 앱에 직접 적은 할일·일정·목표·메모와 앱 설정만 다룹니다. 이름, 연락처, 위치 등 다른 개인정보는 수집하지 않습니다.

2. 저장 위치

데이터는 사용자의 기기(Windows: 문서\Planner 폴더, 안드로이드: 앱 전용 저장소)에 저장됩니다. 사용자가 Google 계정으로 동기화를 켠 경우에만, 사용자 본인의 Google 드라이브 앱 전용 저장공간(appDataFolder)에 같은 데이터의 사본을 저장합니다.

3. Google 사용자 데이터의 사용

Planner는 https://www.googleapis.com/auth/drive.appdata 권한만 요청하며, 이 권한으로는 Planner가 만든 숨김 파일만 읽고 쓸 수 있습니다. 사용자의 다른 드라이브 파일에는 접근하지 않습니다. Google API로 받은 데이터는 기기 간 플래너 동기화에만 쓰이며, 개발자나 제3자에게 전송·공유·판매되지 않고, 광고나 AI 모델 학습에 사용되지 않습니다. Planner의 Google API 사용은 Limited Use 요건을 포함한 Google API 서비스 사용자 데이터 정책을 따릅니다.

4. 로그인 정보

Google 로그인 후 받은 인증 토큰은 사용자의 기기 안에만 저장됩니다. 별도의 서버는 운영하지 않습니다.

5. 삭제

앱의 설정에서 동기화를 끄고 로그아웃할 수 있으며, Google 계정 → 보안 → 타사 액세스에서 Planner의 접근 권한을 언제든 취소할 수 있습니다. 드라이브에 저장된 앱 데이터는 Google 드라이브 설정 → 앱 관리 → Planner → "숨겨진 앱 데이터 삭제"로 지울 수 있습니다. 기기의 데이터는 앱 데이터 폴더를 지우면 삭제됩니다.
