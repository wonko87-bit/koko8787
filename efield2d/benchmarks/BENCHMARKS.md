# 벤치마크 — Maxwell 2D와 비교용

이 문서는 `python benchmarks/bench.py` 로 자동 생성됩니다 (숫자는 GUI와 같은 계산 경로에서 나온 값).
모델 파일: `benchmarks/models/` (DXF: mm 단위, `.efp`: 이 프로그램용 프로젝트).

## 공통 설정

- 단위 **mm**, 모두 **축대칭**. Maxwell 2D에서는 *Solution type ▸ Geometry mode = Cylindrical about Z*,
  그림은 XY 평면에 **X = r(반지름), Y = z(축 방향)** 로 그립니다 (X ≥ 0).
- 전압은 **peak(크기) 값**으로 입력합니다 (AC도 1000 V = 크기 1000 V). 결과 전계도 peak 값입니다.
- 전위를 지정한 곳 외의 경계는 모두 **자연경계(Neumann)**: 영역 바깥 경계에 Balloon이나 전위 경계를 걸지 마세요.
  (r = 0 축과 모델 끝면은 Maxwell 기본값 그대로 두면 됩니다.)
- 해석 모드 대응: **ES** = Electrostatic, **DC** = DC Conduction, **AC** = AC Conduction (50 Hz).
- Maxwell은 메시를 자동으로 세밀화하므로 *Percent error ≤ 0.1~0.5 %* 가 되도록 수렴시킨 값을 비교하세요 (항목 이름은 버전에 따라 다를 수 있음).
- 모델 B는 z 방향이 대칭이 아닙니다: **접지판이 아래(z = 0), HV 전극이 위**가 되도록 축 방향을 확인하세요.
- 결과는 모두 SI 단위로 환산해 적었습니다 (kV/mm = MV/m).

두 개의 직사각형 (r 방향 폭 × z 방향 높이 20 mm). 끝면(z = 0, z = 20)은 자연경계 → 무한히 긴 동축과 같음.

| 영역 | 꼭짓점 (r, z) [mm] | εr | σ [S/m] |
|---|---|---|---|
| L1 | (5,0) (10,0) (10,20) (5,20) | 2.0 | 1e-12 |
| L2 | (10,0) (20,0) (20,20) (10,20) | 4.0 | 1e-13 |

전극: **r = 5 mm** 선(z 0~20) = **1000 V**, **r = 20 mm** 선(z 0~20) = **0 V**.

## 모델 B — 필렛 전극 + 에폭시 스페이서 + 접지판 (ES)

| 객체 | 꼭짓점 (r, z) [mm] | 재료 / 전위 |
|---|---|---|
| 공기 상자 | (0,0) (60,0) (60,80) (0,80) | 공기 εr = 1 |
| 접지판 | (0,0) (60,0) (60,5) (0,5) | 도체 **0 V** |
| 스페이서 | (0,5) (10,5) (10,45) (0,45) | 에폭시 εr = 4 |
| HV 전극 | (0,45) → (11,45) → 호 → (14,48) → (14,54) → 호 → (11,57) → (0,57) → 닫기 | 도체 **100 000 V** |

HV 전극의 호는 **반지름 3 mm 의 90° 필렛** (중심 (11,48), (11,54); 바깥으로 볼록).
스페이서 윗면(z = 45, r ≤ 10)은 HV 전극의 **평평한 밑면(r ≤ 11)** 에 완전히 맞닿습니다. 스페이서 옆면(r = 10)과 전극 밑면이 만나는
(10, 45)가 전극·스페이서·공기의 삼중점이며, 전극 밑면은 r = 10 ~ 11 구간이 공기에 노출됩니다 (돌출 1 mm + 필렛).
겹치는 부분은 **도체(전극)가 우선, 스페이서가 공기보다 우선**입니다 (Maxwell에서는 공기 상자를 먼저 그리고 나머지를 그 안에 만들면 됩니다).

### 주의

- **전극 모서리·삼중점(전극/스페이서/공기가 만나는 점)의 최대 전계(Emax)는 비교하지 마세요.** 이론상 무한대에 가까워 메시에 따라 값이 계속 변합니다
  (이 프로그램도, Maxwell도 마찬가지). 위 표의 \|E\| 비교 지점은 모두 모서리에서 떨어져 있습니다.
- Maxwell 쪽 점 \|E\|는 **메시 길이 제한(Mesh Operations ▸ Length Based, 관심 영역 0.25 mm 이하)** 을 주고 Percent Error 를 낮춘 뒤 읽으세요. 모델 A 에서 자동 메시는 점 전계가 1.6 % 어긋났고 0.1 mm 제한에서 해석해와 일치했습니다 (`MAXWELL_GUIDE.md`).
- 점 \|E\|는 이 프로그램이 전위의 중심차분(±1 mm)으로 구한 값입니다 (1차 요소의 요소별 상수 전계는 점 값이 ±4 % 흔들려 쓰지 않음).
  Maxwell의 점 값과 비교하되, 전위와 정전용량이 먼저 맞는지 보세요 — 그쪽이 훨씬 엄밀한 비교입니다.
- 정전용량은 공기 상자 크기(60 × 80 mm)와 자연경계 조건에 의존합니다. Maxwell에서 Balloon을 쓰면 값이 달라집니다.
