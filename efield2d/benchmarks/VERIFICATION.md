# 검증 기록 — Maxwell 2D 대조 결과

이 문서는 Maxwell 2D 와의 대조 결과를 기록합니다 (사용자가 Maxwell 에서 얻은 값, 이 프로그램의 기대값은 `BENCHMARKS.md` / `MAXWELL_GUIDE.md`).
Maxwell 버전은 기록되지 않았습니다.

**Maxwell 메시 설정**: 모델 A 는 요소 길이 0.1 mm 제한 (아래 표의 '자동 메시' 행은 제한 없이 돌린 첫 시도). 모델 B 는 **전체 영역에 균등하게 0.25 mm** 길이 제한 (전극 가장자리 등 국부 세밀화 없음).
이 프로그램의 모델 B 기준값은 전체 요소 크기 0.5 mm / 전극 가장자리 0.12 mm (가장 세밀한 0.35 / 0.08 mm 와는 0.1 % 이내) 이므로, 요소 크기 체계가 서로 다름에도 일치한 것.

공기 εr 은 Maxwell 기본값(1.0006)으로 입력 (이 프로그램에서 1.0006 의 영향: C +0.05 %, 전계 ±0.01 % 이내).

## 판정
- 허용 오차(전위 ±0.5 %, 전계 ±3 %, C ±1 %)에 모두 들어오고, 실제 차이는 그보다 한 자릿수 작음 (전위 −0.06~−0.10 %, 전계 −0.29~+0.24 %).
- 모델 B 의 Maxwell 메시는 균등 0.25 mm 라서 삼중점 부근 (z ≈ 40~45) 의 국부 전계는 이 프로그램의 가장자리 세밀화 메시보다 덜 정밀할 수 있음. 비교한 점들은 모두 모서리에서 떨어져 있고 (가장 가까운 연면 경로 z = 40 의 Et 도 +0.08 % 차이) 결과에 영향은 보이지 않음.
- 전위·C·전계가 모두 같은 방향으로 −0.1 % 안팎 어긋나는 것은 전체 스케일의 미세한 차이(전극 치수 입력의 반올림 또는 수렴 정도)로 설명되는 크기.
  (참고: 전극 반지름 0.1 mm → C 0.36 %, 전극 밑면 z 0.1 mm → C 0.15 %.)
- 결론: 이 프로그램의 ES 솔버, 축대칭 정식화, 재료 경계 처리, 연면 경로 평가는 Maxwell 2D 와 일치.

## 미확인
- 모델 B 의 전위 5점 중 (6,25) 는 확인됨: Maxwell 40 233.4 V, 기대 40.27 kV → −0.09 % (기대값이 4자리 반올림이라 ±0.01 %). 나머지 4점 (14,25) (20,50) (30,30) (40,70) 은 미확인 — 경로 전위 4점·C 와 같은 방향·크기의 차이일 것으로 예상.
- DC 전도 / AC 전도 모드의 Maxwell 대조 (모델 A 로 가능, 기대값은 `MAXWELL_GUIDE.md`).
- 삼중점 / 전극 모서리의 Emax 는 메시 의존이라 비교 대상이 아님.
