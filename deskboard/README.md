# 🗂️ DeskBoard — 바탕화면 바로가기 · 메모 위젯

자주 가는 폴더와 자주 쓰는 프로그램을 **카테고리별 타일**로 모으고, 그 옆에 **포스트잇 메모**를
붙여 두는 Windows 바탕화면 위젯입니다. 다른 창을 가리지 않게 바탕화면에 깔려 있다가,
`Win + D` 로 바탕화면을 보면 그 위에 나타납니다.

## 기능

- **바로가기 타일**: 폴더 · 프로그램 · 파일 · 웹 주소를 타일로 등록하고 클릭 한 번으로 엽니다.
  탐색기에서 보이는 것과 같은 **실제 아이콘**이 표시되고, 타일마다 바탕색과 아이콘(이모지 또는 그림 파일)을 따로 정할 수 있습니다.
  카테고리로 묶고, 타일을 끌어서 순서를 바꾸거나 다른 카테고리로 옮길 수 있습니다.
- **찾아서 열기**: 헤더의 찾기 칸에 이름 몇 글자를 치면 맞는 타일만 남고, `Enter` 로 첫 번째 것을 엽니다.
  단축키로 위젯을 불러오면 커서가 바로 찾기 칸에 있어서, `Ctrl + Alt + D` → `yp` → `Enter` 처럼 쓸 수 있습니다.
- **끌어다 놓기**: 탐색기나 바탕화면에서 파일 · 폴더를 위젯 위로 끌어다 놓으면 바로가기가 됩니다.
  탐색기 창이 위젯을 가리고 있으면 먼저 `Ctrl + Alt + D` 로 위젯을 불러오세요. 불러온 위젯은 파일을 집어
  끌어오는 동안 그 창 위에 남아 있고, 놓은 뒤 다른 창을 쓰면 제자리로 돌아갑니다.
- **포스트잇 메모**: 오른쪽 메모판에 메모를 붙이고, 위쪽 띠를 끌어 옮기고, 모서리를 끌어 크기를 바꿉니다.
  메모지 안에서는 **빈 곳을 클릭한 자리에 글상자**가 생겨서, 여러 항목을 여러 줄 · 여러 칸으로 자유롭게 놓을 수 있습니다.
  아무것도 적지 않은(공백뿐인) 글상자는 다른 곳을 누르면 사라집니다.
  글상자를 옮기거나 새로 만들 때 다른 글상자의 왼쪽 끝 · 윗줄 근처에서는 거기에 **맞춰 붙어** 줄과 칸이 가지런해지고,
  글상자 오른쪽 끝을 끌어 **폭**을 정할 수 있습니다.
- **메모판 페이지**: 메모판을 탭으로 나눠(예: 메모 / 업무 / 개인) 넘겨 가며 씁니다.
  글자를 선택해 **굵게** · *기울임* · 글자 색(기본 + 5색)을 입힐 수 있고, 메모마다 종이 색(5가지)과 글자 크기를 정하며,
  **체크리스트**로 바꿔 쓸 수도 있습니다. 적는 대로 자동 저장됩니다.
- **바탕화면 고정**: 평소에는 모든 창의 맨 아래에 있고 클릭해도 앞으로 튀어나오지 않습니다.
  `Win + D`(바탕화면 보기)를 누르면 바탕화면 위에 보이고, 다른 창으로 돌아가면 다시 내려갑니다.
  작업 표시줄과 `Alt + Tab` 목록에는 나타나지 않습니다.
- **불러오기**: 단축키(기본 `Ctrl + Alt + D`)나 트레이 아이콘 클릭으로 위젯을 다른 창들 위로 불러옵니다.
  다른 프로그램을 클릭하거나(마우스에서 손을 떼는 순간) 단축키를 한 번 더 누르면 제자리로 돌아갑니다.
- **배치 조절**: 자물쇠 버튼을 풀면 헤더를 끌어 위치를, 가장자리를 끌어 크기를, 가운데 선을 끌어
  바로가기/메모 영역 비율을 바꿉니다. 다시 잠그면 고정됩니다. 위치와 크기는 다음 실행 때도 유지됩니다.
- **모양 설정**: 테마 4종(다크 · 라이트 · 파스텔 민트 · 파스텔 라벤더), 타일 크기, 배경 불투명도, 메모 글꼴.
- **되돌리기와 백업**: 메모 · 바로가기 · 카테고리 · 페이지를 지우면 바로 지워지고, 잠깐 동안 뜨는 "되돌리기"(또는 `Ctrl + Z`)로
  되살릴 수 있습니다. 보드는 하루 한 번 자동으로 백업되어 2주 치가 보관됩니다.
- **그 밖에**: Windows 시작 시 자동 실행, 보드 내보내기/가져오기, 자동 업데이트.

## 사용법

| 하고 싶은 일 | 방법 |
|---|---|
| 바로가기 추가 | 파일 · 폴더를 위젯에 끌어다 놓기 (창에 가려 있으면 `Ctrl + Alt + D` 로 먼저 불러오기). 또는 헤더의 **＋ 바로가기**, 카테고리 이름 옆 **＋** |
| 바로가기 편집 · 삭제 · 색/아이콘 변경 | 타일 우클릭 → **편집…** / **삭제** |
| 관리자 권한으로 실행 | 프로그램 타일 우클릭 → **관리자 권한으로 열기** (Windows 가 확인 창을 띄웁니다) |
| 타일 순서 · 카테고리 변경 | 타일을 끌어다 놓기 |
| 카테고리 이름 변경 · 순서 · 삭제 | 카테고리 이름 우클릭 (또는 이름 옆 **⋯**) |
| 메모 추가 | 헤더의 **＋ 메모**, 또는 메모판 빈 곳 더블클릭 |
| 종이 색 · 체크리스트 전환 · 글자 크기 · 떼기 | 메모에 마우스를 올리면 위쪽 띠에 나오는 버튼들 |
| 바로가기 찾아 열기 | 헤더의 **바로가기 찾기** 칸에 이름 일부를 치고 `Enter` (`Esc` 로 지움) |
| 메모지 안에 글 적기 | 빈 곳을 클릭 → 그 자리에 글상자. 옮길 때는 글상자 위쪽에 나타나는 얇은 손잡이를 끌기 |
| 글상자 줄 맞추기 · 폭 정하기 | 다른 글상자 근처로 끌면 줄이 맞춰짐. 오른쪽 끝을 끌면 폭 조절(더블클릭하면 내용에 맞춤) |
| 메모판 페이지 | 메모판 위쪽 탭을 클릭해 이동, **＋** 로 추가, 탭 우클릭으로 이름 변경 · 순서 · 삭제 |
| 메모를 다른 페이지로 | 메모 위쪽 띠를 우클릭 → 보낼 페이지 선택 |
| 지운 것 되살리기 | 지운 직후 아래에 뜨는 **되돌리기** 를 누르거나 `Ctrl + Z` |
| 예전 내용으로 되돌리기 | 설정 → **가져오기…** 에서 자동 백업 파일(`board-날짜.json`) 선택 |
| 글자 굵게 · 기울임 · 색 | 글자를 선택한 뒤, 편집 중에 메모 아래쪽에 나타나는 **B** / *I* / 색 단추 (`Ctrl + B`, `Ctrl + I` 도 됩니다) |
| 체크리스트 쓰기 | `Enter` 로 다음 항목, 빈 항목에서 `Backspace` 로 삭제 |
| 다른 창을 쓰다가 위젯 보기 | `Ctrl + Alt + D` (설정에서 변경) 또는 트레이 아이콘 클릭 |
| 위젯 위치 · 크기 변경 | 자물쇠 버튼으로 잠금 해제 → 끌어서 조절 → 다시 잠금 |
| 테마 · 글꼴 · 단축키 · 자동 실행 · 백업 | 설정(슬라이더 아이콘) |
| 종료 | 설정 → **DeskBoard 종료**, 또는 트레이 아이콘 우클릭 |

> 실행하면 위젯은 열려 있는 창들 **아래**에 나타납니다. 아무것도 안 뜬 것처럼 보이면 `Win + D` 나 `Ctrl + Alt + D` 를 눌러 보세요.

## 데이터

`%APPDATA%\com.koko8787.deskboard\` 에 저장됩니다. 외부로 보내는 것은 없습니다.

- `board.json` — 카테고리 · 타일 · 메모 · 설정
- `window.json` — 위젯 창의 위치와 크기
- `backups\board-YYYYMMDD.json` — 그날 처음 바꾸기 직전의 보드. 최근 14개를 남깁니다.

`board.json` 을 읽을 수 없게 되면 덮어쓰지 않고 `board.corrupt-….json` 으로 남겨 둔 뒤 새로 시작합니다.

## 기술 스택

- [Tauri 2](https://tauri.app) (Rust 백엔드 + WebView2 UI), React + TypeScript + Vite
- 바탕화면 고정: `src-tauri/src/desktop.rs` — 맨 아래에 둔 표식 창보다 셸의 바탕화면 창이 위로 올라오면
  "바탕화면 보기" 상태로 보고, 그동안 위젯을 그 바탕화면 창에 딸린 창으로 붙여 둡니다.
  (올라오는 창은 Windows 10 에서는 `WorkerW`, Windows 11 24H2 에서는 `Progman` 입니다.)
- 탐색기(explorer.exe)가 죽거나 재시작되어도 위젯은 그대로 남고, 새 바탕화면 창을 기준으로 계속 동작합니다.
- 파일 끌어다 놓기: `src-tauri/src/dropzone.rs` — 위젯이 직접 "놓기 받기"를 등록하고, 웹뷰 안쪽 창이 새로 생기면
  그때마다 다시 등록합니다. (웹뷰 라이브러리에 맡기면 창이 늦게 생긴 경우 등록이 빠져 금지 표시 커서가 떴습니다.)
- 문제 진단: 환경 변수 `DESKBOARD_LOG` 에 파일 경로를 주고 실행하면 위젯을 붙이고 뗄 때, 파일을 끌어올 때마다 기록을 남깁니다.

## 개발

```bash
cd deskboard
npm install
npm run tauri dev      # 개발 모드 실행
npm run tauri build    # 설치 파일(NSIS) 빌드 → src-tauri/target/release/bundle/nsis/
```

`npm run dev` 만 실행하면 브라우저에서 화면만 미리 볼 수 있습니다 (저장은 localStorage, 실행은 흉내만).

### 릴리스와 자동 업데이트

**DeskBoard Release** 워크플로가 서명된 설치 파일을 릴리스로 발행합니다. 버전을 올려 푸시하면 자동으로 돌고
(그 버전이 이미 발행되어 있으면 건너뜁니다), 수동 실행이나 `deskboard-v*` 태그 푸시로도 돌릴 수 있습니다.
앱은 `deskboard-updater` 릴리스의 `latest.json` 을 읽어 새 버전을 알아챕니다.

- 버전은 `package.json`, `src-tauri/Cargo.toml`, `src-tauri/tauri.conf.json` 세 곳을 함께 올립니다.
- 같은 저장소의 FileBox 가 "최신 릴리스"를 자동 업데이트에 쓰고 있어서, DeskBoard 릴리스는 그 자리를 차지하지 않도록
  prerelease 로 발행합니다. 서명 키는 FileBox 와 같은 저장소 시크릿(`TAURI_SIGNING_PRIVATE_KEY`)을 씁니다.

GitHub Actions 의 **DeskBoard Windows Build** 워크플로가 테스트 · 설치 파일 빌드를 하고,
실제 Windows 바탕화면에서 `Win + D` 동작과 위치·크기 조절을 확인하는 스모크 테스트(`scripts/smoke-desktop.ps1`)를 돌립니다.
설치 파일은 워크플로 실행 결과의 `DeskBoard-windows-installer` 아티팩트로 받을 수 있습니다.
