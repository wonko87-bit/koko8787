# 📦 FileBox — 파일 관리함

새로 받은 파일을 **자동으로 한곳에 모으고**, 폴더 이동 없이 **가상으로 분류**한 뒤,
자주 쓰는 폴더로 **원클릭 이동**하는 Windows용 파일 관리 앱입니다.

## 동작 개념

```
다운로드 폴더 (감시)
      │  새 파일 감지 (다운로드 완료까지 대기)
      ▼
관리함 폴더 (자동 수집 · 실제 파일은 여기 한곳에만 보관)
      │  앱 안에서 카테고리/태그로 가상 분류 (파일은 움직이지 않음)
      ▼
즐겨찾기 폴더 (최종 저장처 · 원클릭 이동으로 사용자가 확정)
```

- **자동 수집**: 감시 폴더(기본: 다운로드)에 새 파일이 생기면 관리함 폴더로 이동합니다.
  브라우저 임시파일(`.crdownload`, `.part` 등)은 무시하고, 파일 크기가 안정된 뒤에만 수집합니다.
- **가상 분류**: 관리함 안에서는 파일을 실제로 옮기지 않고 카테고리(문서/이미지/영상…)와
  태그로만 정리합니다. 확장자 기본 분류 + 사용자 규칙으로 자동 분류됩니다.
- **원클릭 이동**: 최종 저장은 항상 사용자가 결정합니다. 즐겨찾기 폴더를 등록해두면
  파일 카드와 알림 토스트에 추천 버튼이 떠서 클릭 한 번으로 이동합니다.
- **패턴 학습**: 파일을 즐겨찾기로 보낼 때마다 확장자·파일명 토큰을 기억해서
  비슷한 파일이 오면 그 폴더를 우선 추천합니다. (전부 로컬에서 동작, 외부 전송 없음)
- **끌어다 놓기**: 감시 폴더 밖의 파일도 FileBox 창에 끌어다 놓으면 바로 수집됩니다.
- **일괄 처리**: 검색·카테고리 필터로 추린 뒤 여러 파일을 한 번에 이동·분류·제거할 수 있습니다.
- **되돌리기**: 잘못 보낸 파일은 기록 탭에서 관리함으로 되돌릴 수 있고, 그때 남은 학습 기록도 함께 취소됩니다.
- **태그**: 카테고리와 별개로 여러 태그를 붙여 교차 분류하고 검색할 수 있습니다.
- **트레이 상주**: 창을 닫아도 트레이에 남아 감시를 계속합니다. 종료는 트레이 메뉴에서.
- **시작 프로그램 등록**: 설정에서 윈도우 시작 시 자동 실행을 켤 수 있습니다.

## 주요 화면

| 탭 | 설명 |
|---|---|
| 관리함 | 수집된 파일을 카테고리별로 표시. 검색·필터, 다중 선택 일괄 처리, 태그, 추천 즐겨찾기 버튼, 열기/위치 보기 |
| 기록 | 이동 완료된 파일과 목적지 이력. 되돌리기 / 개별·전체 삭제 |
| 즐겨찾기 | 최종 저장처 폴더 등록/관리 |
| 규칙 | 확장자·키워드 → 카테고리/추천 즐겨찾기 규칙 관리 |
| 설정 | 감시 폴더, 관리함 폴더, 자동 수집/토스트/일시정지 |

## 기술 스택

- [Tauri 2](https://tauri.app) (Rust 백엔드 + WebView UI) — 상주 메모리 수십 MB 수준
- React + TypeScript + Vite
- 파일 감시: [`notify`](https://crates.io/crates/notify) crate
- 데이터 저장: 앱 데이터 폴더의 JSON (`store.json`)

## 개발

```bash
cd filebox
npm install
npm run tauri dev      # 개발 모드 실행
npm run tauri build    # Windows에서 NSIS 설치 파일 생성
```

Rust 백엔드 단위 테스트:

```bash
cd filebox/src-tauri
cargo test
```

## Windows 설치 파일 받기

GitHub Actions의 **FileBox Windows Build** 워크플로가 푸시마다 NSIS 설치 파일을 만들어
`FileBox-windows-installer` 아티팩트로 업로드합니다.
(Actions 탭 → 해당 실행 → Artifacts에서 다운로드)
